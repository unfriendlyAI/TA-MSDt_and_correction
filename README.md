# TA-MSD: Trimmed Mean and Ensemble-Based Correction

This repository contains the code and experimental results accompanying the following publications:

- Lavrynenko R, Kirichenko L, Ryabova N, Lavrynenko S.  
  **Impact of outliers on median-based and mean-based methods for anomalous diffusion exponent estimation.**  
  *J. Phys. Photonics* [Internet]. 2025 Mar 24;7(2):025018.  
  DOI: [10.1088/2515-7647/adc04e](http://dx.doi.org/10.1088/2515-7647/adc04e)

- Lavrynenko R, Kirichenko L, Yakovlev S, Lavrynenko S, Ryabova N.  
  **Ensemble-Based Correction for Anomalous Diffusion Exponent Estimation in Single-Particle Tracking.**  
  *Appl. Sci.* [Internet]. 2025 Jul 18;15(14):8000.  
  DOI: [10.3390/app15148000](http://dx.doi.org/10.3390/app15148000)
